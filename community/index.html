Community: bring your C++ library to the web

webcpp is open to C++, JavaScript, crypto and AI developers who build decentralized applications for the web. The same rules apply whatever agent system you use.

Contributing

CONTRIBUTING.md gives the rules for contributors: what webcpp is, the rules every library keeps, how a change is made and reviewed, and how commits are written.

CONTRIBUTING.md

The rulebook

AGENTS.md is the rulebook for porting a library to webcpp, which coding agents and people follow alike: what a library builds on, how it is tested on every target, and how it is documented.

Bringing a library

A library joins webcpp through an issue that proposes it: what it ports, or what it does, and why it belongs on the web.
