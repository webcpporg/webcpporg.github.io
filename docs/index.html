webcpp

webcpp brings to C++ the libraries that other languages use for the web. Each is a header-only C++20 library, a port of a widely used original at an exact version or a library of webcpp’s own, built and tested with b2, natively and for WebAssembly, and documented on a page of its own, with its API reference. webcpp follows Boost’s guidelines and model; its source is at webcpporg/webcpp.

Libraries

Each library’s name leads to its page: the guide that teaches it, its guarantees, its API reference and how it is tested.

Test matrix

Every library is tested on every target it declares, natively and for WebAssembly: on wasm32-wasip2 and wasm32-wasip3 with wasmtime, and with Emscripten, whose programs node runs. The test matrix shows each test and example of each library by lane, with the log of every failure.

Getting started

With Boost 1.92 or newer and b2 installed, a checkout of the superproject builds and tests every library. trystero needs three libraries that webcpp does not build yet, which its page says how to install: without them, b2 test builds and tests every other library and leaves trystero out, saying so once for each library it did not find:

git clone --recursive https://github.com/webcpporg/webcpp
cd webcpp
b2 test

A b2 project uses a library through /webcpp/<name>//<name>; CMake or a plain compiler uses the headers that b2 install --prefix=<dir> copies to <dir>/include/webcpp/. The README lists the prerequisites and how to configure them, and AGENTS.md is the rulebook for porting a library to webcpp.

webcpp 0.1.0

In preparation: no tag names this version yet, and its libraries’ entries are their changelogs’ "Unreleased" sections.

New Libraries

  • config: webcpp’s configuration, which every library includes first: the target, exceptions and the version, from R.

  • document: a header-only JSON document for C++20 that behaves as JavaScript does, exact in decimal, in one relocatable binary image, with a JavaScript module, from R.

  • idna: a header-only library of internationalized domain names for C++20: Punycode, UTS 46 and IDNA2008 validity over Unicode 17.0.0 tables, from R.

  • lexical: header-only validators of JSON Schema’s string formats for C++20, allocating nothing, each also a Boost.URL grammar rule, from R.

  • pratt: a header-only Pratt-parsing engine for C++20, with a decimal calculator built on it, from R.

  • trystero: a port of Trystero 0.26.0, serverless WebRTC rooms wire-compatible with the original, for C++20, from R.

  • wasi: a header-only HTTP handler for C++20 programs built as WebAssembly components, covering WASI 0.2 and WASI 0.3, from R.

  • xactor: a header-only, deterministic actor system for C++20, from R.

  • xstate: a header-only port of XState’s state machines and actors for C++20, from R.
