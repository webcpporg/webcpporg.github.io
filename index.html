Where C++ and the web meet

webcpp brings the best of C++ to the web, and the libraries web developers use most to C++, for everyone who builds decentralized applications.

See the librariesGet started

The same code, wherever it runs

Each library is header-only C++20, built and tested with b2 on every target it declares. Each target has its purpose:

  • The browser

    Compiled to WebAssembly with Emscripten, beside the page's JavaScript.

  • A server

    As a WASI component in a WebAssembly container, run by wasmtime or a cloud.

  • Native

    Compiled by your own compiler, as any C++ library is.
